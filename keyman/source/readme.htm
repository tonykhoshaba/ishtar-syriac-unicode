Ishtar Syriac — Ramsina layout

Version 1.0.0. Unicode text, with the familiar physical Ramsina QWERTY mapping. On desktop use Shift and right Alt (AltGr). On phones and tablets use Shift, Alt and 123; hold a key for alternatives. The top row contains vowels and marks; Shift gives digits.

Talqana: desktop backslash; mobile 123 then backslash-position silencer key. Seyame: 0 on the main layer. Dot below: 8. Rukakha: Alt+R or the consonant shortcuts. Above Majliyana: Alt+F. He dot above: Alt+H.

Taw–Alaph joins automatically in Ishtar. OpenType alternates require an application that supports stylistic sets; a system keyboard cannot force a font feature in every app. Text always remains ordinary Syriac Unicode.

Mobile: install Keyman, then open this KMP package in Keyman and enable its keyboard in system settings. iPhone/iPad: Settings → General → Keyboard → Keyboards → Add New Keyboard → Keyman. Android: enable Keyman in system keyboard settings and choose it as the input method. Desktop: install Keyman for Windows, macOS or Linux, then open the KMP package.

The included font is available inside Keyman on mobile; other apps choose their own display font. Installing a keyboard does not replace the system font.
