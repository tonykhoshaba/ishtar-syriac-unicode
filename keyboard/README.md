# Ishtar Unicode keyboard 1.0.0

This directory contains the browser tester and the 122-entry Ramsina-compatible QWERTY mapping. The installable Keyman package is `../keyman/build/ishtar_syrc.kmp`; it includes desktop, phone and tablet layouts and the matching font.

See [installation](../docs/INSTALLATION.md), [keyboard reference](../docs/KEYBOARD-REFERENCE.md), [known limitations](../docs/KNOWN-LIMITATIONS.md) and [build instructions](../docs/BUILDING.md).

In the browser tester, keep your operating-system layout on English US when using Ishtar QWERTY. Choose System keyboard when using an already installed Syriac input method. The Taw–Alap selector changes one selected word in the formatted preview; Unicode text is unchanged and plain-text exports do not retain those presentation settings. Text and preview settings are stored in the current browser.

Amber keys indicate mapped characters outside Ishtar's coverage. Existing assignments are preserved, including their generic or Syriac-specific marks. Please report the exact Unicode text when a character looks unexpected.
