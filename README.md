# Ishtar Syriac Unicode

A Unicode Eastern Syriac font based on Tony Khoshaba’s Ishtar XP, developed with the help of Yoab Benjamin. This project preserves the original letter designs while adding Unicode character mapping, contextual forms, mark positioning and OpenType ligatures.

**Private release preparation — not yet a public release.** The working font remains named “Ishtar Syriac Unicode Alpha.” Distribution rights and earlier source attribution are being confirmed before a public license is selected.

## What is here

- `output/IshtarSyriacUnicodeAlpha-Regular.ttf`: current working desktop font.
- `output/IshtarSyriacUnicodeAlpha-Regular.woff2`: browser font, when generated by the package script.
- `keyboard/`: Ramsina-editor-compatible QWERTY keyboard and live specimen.
- `tools/`: font conversion, keyboard generation and verification scripts.
- `originals/ISHAR_XP.ttf`: original build input, retained for private provenance review.
- `docs/`: installation, typography, release checklist, attribution and known limitations.

This is not a conversion of text files into an encoding specific to Ishtar. The keyboard enters Unicode Syriac characters; the font supplies their appearance.

## Try the keyboard

Serve this repository with a static web server and open `/keyboard/`. For example:

```sh
python3 -m http.server 8877 --bind 127.0.0.1
```

Keep the system keyboard set to English (US) and use the page’s QWERTY input. Physical keys and clickable Normal, Shift and AltGr layers are supported. The layout preserves 119 assignments from the existing Ramsina review editors, with three additions in unused positions. See `keyboard/README.md` and `keyboard/mapping.csv`.

An installable private test package is now available at `keyman/build/ishtar_syrc.kmp`, with desktop files and phone/tablet touch layouts for Keyman on Windows, macOS, Linux, Android and iPhone/iPad. See `keyman/PLATFORMS.md`. All 122 compiled outputs match the mapping. Real-device installation and app testing remain pending. The browser prototype is still available alongside it.

## Typography

The font includes the 22 core letters, reviewed positional forms, vowels, Seyame, Rukakha, Majliyana, the silence stroke, dotted He and optional ligatures. Word-final Taw–Alap automatically follows the joining rule illustrated on page 4 of Yoab’s lectures. OpenType settings allow separate letters and alternate ligature designs.

Some combined marks have provisional placement. A complete 12-page Kokhva comparison edition has been generated locally with unchanged reviewed text. New Talqana/Seyame and below-mark review sheets are available at `keyboard/refinement-review.html`; their placement still needs visual approval. All 264 single-mark render comparisons remain unchanged. See `docs/KNOWN-LIMITATIONS.md`.

## Development

Use Python 3 in a virtual environment and install `requirements.txt`, then:

```sh
python tools/build_font.py
python tools/build_keyboard.py
python tools/verify_font.py
python tools/verify_taw_alaph.py
```

The build uses the original Ishtar XP font as its input. The original is not automatically licensed for redistribution by the existence of this repository. Font inspection/proof tools may require DejaVu fonts; they do not copy DejaVu outlines into Ishtar.
