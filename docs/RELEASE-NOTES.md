# Ishtar Syriac Unicode 1.0.0

First stable public release, approved by Tony Khoshaba on October 27, 2026.

Release: https://github.com/tonykhoshaba/ishtar-syriac-unicode/releases/tag/v1.0.0

## What is included

- Eastern Syriac Unicode TTF and WOFF2 fonts, internal font version 1.000.
- Keyman package version 1.0.0 with desktop, phone and tablet layouts and the matching font.
- Unicode contextual shaping for the 22 core letters and reviewed positional forms.
- Reviewed vowel and mark placement, Seyame, Rukakha, Majliyana, dotted He, Pe/Fe and selected optional ligatures.
- Automatic word-final Taw–Alap selection, with explicit alternatives in applications supporting the font features.
- The final Lamad outline corrected to original Ishtar location `0x5E`; initial/medial Lamad retains `0x6C`.
- Detached Kap dot positioning also covers the legacy-compatible combining dot used in the sample sentence, without rewriting the text.
- Reviewed Gamal Zlama, Seyame, Rukakha and Majliyana adjustments, including medial Gamal combinations.
- A keyboard preserving 119 Ramsina-editor assignments plus three additions, with all 122 compiled outputs checked.
- Installation, source/build information, keyboard reference, credits and SIL OFL 1.1 notices.

## Scope

Version 1 establishes a stable reference for community use and feedback. Uncommon mark combinations, native mobile behavior and application interoperability will continue to improve in later releases. See KNOWN-LIMITATIONS.md.

A complete Kokhva issue PDF is included as a font specimen. The larger Kokhva corpus is a separate project still in progress and will be released later. Yoab lectures, reviewer accounts, saved revisions and website backend are excluded.

Additional mapped punctuation, combining marks and specialist symbols are deferred to future versions; the complete character list is recorded in [Known limitations](KNOWN-LIMITATIONS.md).
