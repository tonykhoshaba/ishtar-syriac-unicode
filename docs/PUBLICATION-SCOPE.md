# Publication scope for approval

The proposed public repository is https://github.com/tonykhoshaba/ishtar-syriac-unicode, with a v1.0.0 release and the reviewed artifacts.

Included: the Ishtar Unicode font, historical Ishtar XP outline input required to rebuild it, font and keyboard build source, compiled Keyman files, browser tester, review specimens, documentation, license, attribution and checksums.

Included as a font specimen: one complete Kokhva issue PDF, from a separate corpus project still in progress. The full corpus will be released later.

Excluded: Yoab lecture transcriptions, other Kokhva corpus documents and the editor service, reviewer accounts and email addresses, saved user text/revisions, Netlify credentials/configuration, local environment folders, tester email drafts and unsent licensing enquiry drafts.

Making the existing repository public also makes its existing commit history visible. That history includes earlier alpha files and superseded provenance research/enquiry drafts already committed during private preparation. Those are not part of the current Version 1 tree or download package, but removing them from the current tree does not erase them from history. Review that distinction before approving the visibility change. No history rewrite is proposed here.

Tony Khoshaba approved the content, existing-history visibility and public Version 1.0.0 publication on October 27, 2026.
